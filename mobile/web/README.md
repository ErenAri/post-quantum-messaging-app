# PQmsg Web

Web client build and run guidance is documented in [docs/WEB.md](../../docs/WEB.md).

Hosted production shell guidance is documented in [docs/WEB_DEPLOYMENT.md](../../docs/WEB_DEPLOYMENT.md).

Current pilot posture:

- Android messaging is the supported pilot path.
- Web remains demo-only and outside the supported pilot.
- Calling is unavailable from the web UI in this release.

Quick start:

```bash
cd mobile/web
npm install
npm run dev
```
